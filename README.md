# Hi there, I'm Muhammad Farrell Hauzan 👋

### AI Product Engineer | Backend & Web3 Background

I build developer-facing AI tooling on top of strong systems fundamentals. My background is backend and Web3 — Go microservices, Solidity smart contracts, Rust infra — and I now apply that to LLM-powered products: eval pipelines, agentic tools, and code-review automation.
